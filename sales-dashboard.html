CASE STUDY 01 / DATA ANALYTICS

Sales Analytics Dashboard.

An Excel-based data analytics project focused on turning raw sales information into structured insights through data cleaning, Pivot Tables, KPI analysis, charts, and dashboard design.

TOOLS Microsoft Excel
PROJECT TYPE Data Analytics
FOCUS Business Insights
OUTPUT Interactive Dashboard
THE STORY

From raw data to useful information.

01

The Problem

Raw sales information can be difficult to understand when it is spread across rows of data. The goal was to organize the information and identify useful business metrics.

02

What I Did

I cleaned the dataset, worked with Excel formulas, created Pivot Tables, analyzed sales KPIs, created charts, and organized the results into a dashboard.

03

What Came of It

The final dashboard provided a clearer view of sales performance and made it easier to compare departments, products, and overall performance.

KEY METRICS

What the analysis showed.

The analysis produced several useful summary metrics that could be used to understand overall sales performance.

665K TOTAL SALES
83.1K AVERAGE SALES
3 DEPARTMENTS
8 AVERAGE COUNT
MY PROCESS

How I built it.

I followed a structured workflow to move from raw data toward a dashboard that could communicate the results clearly.

01 — Data Cleaning

Checked the dataset for inconsistencies and prepared the information for analysis.

02 — Pivot Tables

Used Pivot Tables to summarize sales and compare performance across categories.

03 — KPI Analysis

Calculated important metrics such as total sales and average sales.

04 — Dashboard

Combined the analysis into a visual dashboard designed for quick understanding.

Dashboard concept.

The final output brought the main metrics and visual analysis together into one view.
